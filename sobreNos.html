Nos unimos a partir da ideia do professor Alexandre Tolentino que nos atribui a criação de uma equipe de 4 ou 5 membros para o desenvolvimento de uma Loja virtual de nossa escolha. Motivo do Projeto

Iniciamos o desenvolvimento desse projeto com o objetivo de aprender programação criando um programa utilizando linguagens como Html, CSS e JavaScript.

Como Foi a Ideia

A ideia inicial do projeto era criar um aplicativo mobile de Agenda. Tendo e vista que a duração do curso era demasiadamente pequena para uma gama massiva de conteúdo, após terminarmos todas as questões teóricas e práticas das aulas, nos sobrou pouco tempo para a entrega desse trabalho, então, optamos por desenvolver um programa web de uma loja virtual.

A opção do nicho da loja foi decidida pelo grupo pois já havia familiaridade de alguns integrantes com esse segmento de mercado, tornando o projeto mais prático e de grande conhecimento da equipe.
